# HAX_PASSWORD

خدمة مستقلة لإدارة كلمة مرور المدير والجلسات، بواجهة عربية وتصميم أسود وأحمر.

## الوظائف
- تسجيل دخول المدير.
- تغيير كلمة المرور بعد التحقق من الحالية.
- فحص قوة كلمة المرور في الواجهة والتحقق منها مجدداً في الخادم.
- تخزين كلمة المرور باستخدام bcrypt داخل ملف بيانات غير منشور.
- إبطال الجلسات السابقة عند تغيير كلمة المرور باستخدام رقم إصدار الجلسة.

## التشغيل
يتطلب Node.js 20 أو أحدث.

```bash
npm install
cp .env.example .env
```

في ملف `.env` على الخادم فقط:
- `JWT_SECRET`: سلسلة عشوائية لا تقل عن 48 حرفاً.
- `BOOTSTRAP_ADMIN_USERNAME`: اسم المدير الأول.
- `BOOTSTRAP_ADMIN_PASSWORD`: كلمة مرور أولية فريدة لا تقل عن 14 حرفاً، وتحتوي أحرفاً كبيرة وصغيرة ورقماً ورمزاً.
- `ALLOWED_ORIGINS`: اتركه فارغاً عند استخدام الواجهة والخادم على النطاق نفسه.

ثم شغّل:

```bash
npm start
```

في أول تشغيل، ينشئ الخادم سجل المدير داخل `data/admin.json` ويحفظ تجزئة كلمة المرور فقط. بعد ذلك لن يعيد إنشاء الحساب من متغيرات البيئة. احفظ مجلد `data` في مساحة تخزين دائمة؛ فقدانه يعني فقدان سجل المدير.

## API
- `POST /api/auth/login`
- `GET /api/security/status`
- `POST /api/password/change`
- `GET /health`

رمز الدخول قصير العمر، ويُرفض تلقائياً بعد تغيير كلمة المرور. لا تحفظ كلمات المرور في LocalStorage أو ملفات الواجهة.

## حماية المستودع
المستودع عام، لذلك لا تضع ملف `.env` أو مجلد `data` أو أي كلمة مرور حقيقية فيه. الملفات الحساسة مستثناة في `.gitignore`.
